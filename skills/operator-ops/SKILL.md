# Operator discipline

## When to use
Operating the company day to day.
## Steps
- Start with the morning brief (/api/brief): cash, jobs, blockers.
- Triage the approval queue (green auto, yellow/red need sign-off).
- Skim the audit timeline + escalations; act on failures.
## Guardrails
- /api/halt freezes everything instantly. Money + account actions are human-gated.
- Report results with evidence, never promises.
